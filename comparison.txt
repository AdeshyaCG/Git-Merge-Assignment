When would you prefer a local merge
You would prefer a local merge when you want to combine branches directly on our computer without needing a Pull Request or code-review process.


When is a Pull Request better?
A Pull Request (PR) is better when changes should be reviewed and approved before merging into a shared branch.


After merging a PR on GitHub, which command brings the changes to your computer?

1. git switch main
